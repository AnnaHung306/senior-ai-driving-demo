這個展示包含什麼？

此頁包含三段完整八鏡頭紀錄：第一章是既有訓練場景的感知重播，沒有自主駕駛；第二、三章為實際完成的CARLA閉環紀錄。3D道路、物件與預測來自當時模型輸出；地圖、導航線與自車定位是明示先驗。網站只播放保存結果，不在瀏覽器執行模型或啟動模擬器。JPEG為原始PNG的網頁預覽，完整來源雜湊保存在資料manifest。

1×指模擬時間回放。實際本機運算約秒級，不能把畫面渲染率當成模型推論頻率。此具名路線成功不代表任意路線皆可靠；錯類、漏檢與3D朝向問題仍可能出現在畫面中。

02 / HOW IT WORKS

一條完整的感知與控制流程

八個鏡頭輸入，回到車輛動作。

  1. 01

    同步擷取

    CARLA八路RGB與相機標定，保存同一時刻的環境視角。

    8 × 640 × 360 RGB
  2. 02

    辨識與重建

    凍結模型辨識道路、物件與號誌，融合成俯視道路及三維方框。

    Segmentation · Detection · 3D
  3. 03

    追蹤與規劃

    結合因果追蹤、短期預測與地圖路由，決定循線、減速或停等。

    World model · Route planning
  4. 04

    控制與回饋

    自寫轉向與速度控制器，驅動模擬車輛，再取得下一組影像。

    Steering · Throttle · Brake

04 / GET STARTED

從展示，到自己的實驗

這個公開網頁不需要安裝。要在本機回放或啟動新的駕駛，請依README選擇模式。

無 GPU · 無 CARLA

本機開啟同一份網頁

python -m http.server 8080 --directory docs

在專案根目錄執行，開啟 http://localhost:8080/。

Windows · CUDA · CARLA

操作新的起終點

./Start-NavigationDemo.ps1 -StartSimulator

需要完整模型權重及模擬器；自訂路線可靠性仍受研究版本限制。
